# Cruiser releases

Downloads for **[Cruiser](https://cruiser-ai.com)**, the AI that lives in your cursor: point at anything on your
screen, press one shortcut, and the answer appears right beside it.

## Install

1. Download **`CruiserControlSetup.exe`** from the [latest release](https://github.com/Aadi-web-op/cruiser-releases/releases/latest).
2. Run it. Windows may show *SmartScreen* because the installer isn't code-signed yet:
   choose **More info › Run anyway**.
3. Add your own AI key in **Settings › AI models** (Gemini, OpenAI or Anthropic), or use a local Ollama model.

Cruiser checks this page for updates and installs one only when its SHA-256 matches the
`.sha256` file published beside it.

For 64-bit Windows 11.
